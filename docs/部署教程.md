# 极核 ZEEHO · 部署教程（一键导入版）

> 适用脚本：`zeeho_box_enhanced.js`（v2.11.0）/ `zeeho.js`（v2.5.0） · 更新 2026-09-17
> 平台：Loon / Quantumult X / Surge / Shadowrocket + BoxJS

---

## 一、两种部署路线

| 路线 | 说明 | 推荐 |
|---|---|---|
| **A. 一键导入** | 导入仓库提供的模块 / 插件 / 订阅，自动写好全部规则与 MITM | ✅ 最省事，首选 |
| **B. 手动配置** | 手动粘贴脚本规则到配置文件 | 需要自定义规则时用 |

> 无论哪种路线，**都必须**安装并信任 MITM 根证书，否则抓不到极核 App 的加密接口。

## 二、路线 A：一键导入

### A1. BoxJS（跨工具，最推荐）
在 BoxJS 中添加订阅源：

```
https://raw.githubusercontent.com/cluck798/ZEEHO/refs/heads/main/script/boxjs/zeeho.boxjs.json
```

导入后浏览器访问面板：
- **Surge / Loon**：`http://zeeho.box`
- **Quantumult X**：`http://www.example.com`

面板内完成账号管理、抓 Token、签到、盲盒、车辆数据、远程控车。

### A2. Surge（模块）
Surge → **模块** → **安装新模块**，粘贴：

```
https://raw.githubusercontent.com/cluck798/ZEEHO/refs/heads/main/modules/zeeho.sgmodule
```

### A3. Loon（插件）
Loon → **插件** → 添加，粘贴：

```
https://raw.githubusercontent.com/cluck798/ZEEHO/refs/heads/main/modules/zeeho.plugin
```

### A4. Quantumult X（订阅）
1. `[rewrite_remote]` 添加：
```
https://raw.githubusercontent.com/cluck798/ZEEHO/refs/heads/main/script/zeeho_qx.conf, tag=极核ZEEHO, enabled=true
```
2. `[task_local]` 添加签到任务（conf 内已含，也可手动加）：
```
0 7 * * * https://raw.githubusercontent.com/cluck798/ZEEHO/refs/heads/main/script/zeeho.js, tag=极核每日签到, img-url=https://raw.githubusercontent.com/cluck798/ZEEHO/main/ZEEHO.png, enabled=true
```

## 三、路线 B：手动配置

### B1. Loon / Surge — `[Script]` 段
```
# 面板 + 极核API自动捕获appId/appSecret（访问 http://zeeho.box 打开面板）
http-request ^https?://(zeeho\.box|.*zeehoev\.com)/.* script-path=https://raw.githubusercontent.com/cluck798/ZEEHO/refs/heads/main/script/zeeho_box_enhanced.js, requires-body=true, timeout=60, tag=极核面板

# 极核Token自动捕获（打开极核App → 我的页面）
http-response ^https:\/\/tapi\.zeehoev\.com\/v1\.0\/mine\/cfmotoservermine\/setting script-path=https://raw.githubusercontent.com/cluck798/ZEEHO/refs/heads/main/script/zeeho.js, requires-body=true, timeout=30, tag=极核抓Token

# 极核每日签到（每天 07:00）
cron "0 7 * * *" script-path=https://raw.githubusercontent.com/cluck798/ZEEHO/refs/heads/main/script/zeeho.js, timeout=120, tag=极核每日签到
```

### B2. MITM
```
hostname = tapi.zeehoev.com, h5.zeehoev.com, zeeho.box
```
> Quantumult X 用 `www.example.com` 而非 `zeeho.box`（QX 需真实可解析域名）。

## 四、通用使用步骤

1. **装证书**：开启 MITM，安装并信任根证书；iOS 到「设置 → 通用 → 关于本机 → 证书信任设置」开启完全信任。
2. **导入**：按上面路线 A / B 完成。
3. **抓 Token**：保持代理 + MITM，打开**极核 ZEEHO App** → 进入「我的」页面，脚本自动捕获 Token。
   - 也可在面板配置页手动粘贴 Token（自动去除 `Bearer ` 前缀、空格换行、引号）。
4. **打开面板**：
   | 工具 | 浏览器访问 |
   |---|---|
   | Surge / Loon | `http://zeeho.box` |
   | Quantumult X | `http://www.example.com` |
5. **（可选）云端控车密钥**：配置页 → 签名密钥 → 填写 32 位 AES 密钥并保存；未填写时开 / 关锁按钮自动禁用。

## 六、常见问题

| 问题 | 解决 |
|---|---|
| 面板打不开 | 检查 MITM 是否含 `zeeho.box`；QX 用 `www.example.com` |
| 抓不到 Token | 确认根证书已信任；代理开启状态下重新打开极核 App 一次 |
| 签到报「操作频繁」 | 多账号会限流，脚本已内置退避重试；可错峰（不同账号不同 cron） |
| 车辆数据全为 0 | App 更新后接口字段变化，等待脚本适配 |
| 开 / 关锁提示未配置 | 到配置页填写 AES 密钥并保存 |
