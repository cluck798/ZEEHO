手动导入步骤：
QX → 右下角风车 → 重写 → 规则资源 → 右上角 + → 粘贴链接 → 标签填「极核签到」→ 保存

2添加每日签到定时任务

0 7 * * * https://raw.githubusercontent.com/cluck798/ZEEHO/main/script/zeeho.js, tag=极核签到, img-url=https://raw.githubusercontent.com/cluck798/ZEEHO/main/ZEEHO.png, enabled=true
已复制到剪贴板
添加步骤：
QX → 右下角风车 → 任务 → 右上角 + → 粘贴代码 → 保存
每天早上 7:00 自动执行签到

3确认 MITM 已开启

  • QX → 右下角风车 → MitM
  • 确认 hostname 包含：tapi.zeehoev.com, zeeho.box
  • 确认证书已安装并在系统设置中信任
  • 开启 重写 和 MitM 总开关

4开始使用

  • 打开极核 App → 进入「我的」页面，自动抓取 Token
  • 浏览器访问 http://zeeho.box 查看看板
  • 访问 http://zeeho.box/config 修改配置
  • 每天 7:00 自动签到，推送结果通知
